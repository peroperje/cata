Build a production-ready, dockerized, k8s-ready, independently deployable Scrapy CrawlSpider service that discovers jobs matching a user's profile. The service must interact with an existing external API for data retrieval and storage.

Core Integration:

API Integration:

Fetch CV: At startup, the service must call an API endpoint on existing API  to retrieve the latest user's CV text.
/home/petar/Projects/cata-chrome-extension/apps/api/app/api/v1/cvs.py

Post Jobs: When a relevant job is found, the service must send a POST request to the API (e.g., POST /jobs/found) with the job details and similarity score.

Dynamic Keyword Extraction: Use spaCy (en_core_web_md) to extract a "Skill Vector" from the CV text received via API.

Spider Logic: Use CrawlSpider with LinkExtractor to follow links. Use CV keywords to prioritize or filter URLs.

NLP Match Pipeline:

For every page crawled, calculate the Cosine Similarity between the page content and the user's CV.

Only jobs above a defined threshold should be sent to the API.

State Management: Use Redis via scrapy-redis to manage the crawling queue and ensure the system is distributed and persistent.

Modular Codebase Structure:

api_client.py: Centralized service for all HTTP communication with the existing API (fetching CV, posting results).

nlp_utils.py: Logic for spaCy vectorization and similarity calculations.

job_spider.py: The CrawlSpider implementation using LinkExtractor.

pipelines.py: Scrapy pipeline that triggers nlp_utils and api_client.

Docker & Environment:

Provide a Dockerfile and docker-compose.yml (Scrapy + Redis).

Use .env for API Base URL, API Keys, and Redis connection strings.

Requirements: scrapy, scrapy-redis, spacy, requests, scikit-learn, python-dotenv.
